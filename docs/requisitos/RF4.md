# Registro de Devolução

**COMO** Bibliotecário,  <br>
**QUERO** registrar a devolução de um livro  <br>
**PARA** atualizar a disponibilidade do exemplar no sistema.

**Critérios de Aceitação:**

- Deve ser possível localizar o empréstimo ativo
- O sistema deve registrar a data de devolução
- O sistema deve atualizar a quantidade de exemplares disponíveis
- O sistema deve permitir a devolução apenas de empréstimos ativos
