# Cadastro de Livros

**COMO** Bibliotecário,
**QUERO** cadastrar um novo livro no sistema
**PARA** que ele possa ser disponibilizado para empréstimo aos usuários.

**Critérios de Aceitação:**

- Deve ser possível informar o título do livro
- Deve ser possível informar o autor do livro
- O sistema deve impedir o cadastro de livros com ISBN duplicado
- O sistema deve validar que o número de exemplares é maior que zero
