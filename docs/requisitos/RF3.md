# Registro de Empréstimo

**COMO** Bibliotecário,
**QUERO** registrar o empréstimo de um livro
**PARA** controlar quais livros estão emprestados para quem.

**Critérios de Aceitação:**

- Deve ser possível selecionar o usuário que realizará o empréstimo
- Deve ser possível selecionar o livro disponível
- O sistema deve impedir empréstimo de livros sem exemplares disponíveis
- O sistema de registrar automaticamente a data do empréstimo
