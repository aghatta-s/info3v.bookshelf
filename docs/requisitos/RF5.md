# Controle de Atrasos

**COMO** Bibliotecário,
**QUERO** identificar empréstimos em atraso
**PARA** aplicar regras ou notificações aos usuários.

**Critérios de Aceitação:**

- O sistema deve calcular automaticamente a data prevista de devolução
- O sistema deve identificar empréstimos com a data vencida
- O sistema deve permitir listar usuários com atraso
- O sistema deve exibir a quantidade de dias em atraso
